Q: How should a J411 source inference answer use the source?
A: Model answer: Make a valid inference, support it with source detail, then use contextual knowledge. Marking points: Inference; precise detail; relevant context. Common trap: Copying the source without explaining what it suggests.
Q: How should a J411 organised summary be constructed?
A: Model answer: Organise examples around a historical connection such as change or cause. Marking points: Accurate examples; clear connection; logical reasoning. Common trap: Listing events without analysing their relationship.
Q: How should a J411 explanation answer develop a cause?
A: Model answer: Explain how a reason led to the outcome, supported by precise evidence. Marking points: Accurate knowledge; causal link; developed explanation. Common trap: Naming causes without explaining their effects.
Q: How should a J411 18-mark judgement answer reach the highest levels?
A: Model answer: Explain evidence on both sides and reach a supported judgement. Marking points: Strong knowledge; developed reasoning; balanced argument; clear judgement. Common trap: One-sided assertions or a list of facts.
Q: How should a J411/33 15-mark usefulness answer assess sources and interpretations?
A: Model answer: Assess the interpretation and sources for the stated issue using context. Marking points: AO1 context; source analysis (AO3); interpretation analysis (AO4); supported judgement. Common trap: Asserting bias or discussing only one item.
