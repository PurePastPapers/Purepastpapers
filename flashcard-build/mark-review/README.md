# Independent MARK review

All 92 original cards are in `../mark-reviewed.json`: 64 Psychology and 28 Sociology. Original fronts, stable keys, catalogue card IDs and catalogue IDs are preserved. `sources.tsv` records the specific source and verdict for each original key. `CHANGES.md` records the changes and remaining source-access limitation. `quarantined.json` is empty.

The sign-test working is recomputed from the question: six plus signs, two minus signs, two ties, so s = 2 and effective N = 8. Other checked calculations include population SD sqrt(8/3) = 1.63, 18/60 = 3/10 = 30%, mean 5/median 4/mode 4/range 7, 5/10 = 50%, and scattergram Pearson r approximately -0.916. The no-count sign-test card now states why no numeric value is available. All backs have a model-answer label, marking points and a specific trap. Source and detailed change notes are in the accompanying files.

Two official 2024 AQA mark schemes were checked from indexed official text, but the direct PDF links returned 404 in this environment. They should be rechecked when accessible. The scattergram media reference was preserved; delivery and rendering of the original media need separate verification. This review does not authorise or carry out publication.
