## Checkpoint 1: specification (16 November 2026)

**Status: no Computer Science questions are imported yet.** The 8 existing rows are
hidden demo records (now tagged to official leaves).

`data/specs/OCR_ALEVEL_CS_H446.json` is generated by `tools/cs/build_spec.py` from OCR's
H446 specification (Version 3.0, April 2026, SHA256 `8551bc26…50764a44`) and H046
specification (Version 2.0, February 2026, SHA256 `74456000…ecd6b`). Other revisions
are refused.

- OCR prints a two-column table: numbered topic on the left, lettered points on the
  right. The parser splits the columns by word position and ignores the chapter-tab digit
  printed in either page margin.
- **113 leaves**: the 111 lettered points of the 24 numbered topics (1.1.1 to 2.3.1), id
  `OCR_CS_1.1.1a`, printed code `1.1.1(a)`, OCR wording verbatim with source pages; 1.5.2
  is printed as one unlettered paragraph, so its leaf is `OCR_CS_1.5.2_whole`, code
  `1.5.2` (no letter is invented). Plus 2 AS-only leaves.
- Tree: OCR's printed groups 1.1 to 2.3 (component recorded) > numbered topics (the
  earlier ids `OCR_CS_1.1.1` etc. are kept as topic ids) > lettered points. The
  programming project (section 3, components 03/04) is coursework and not exam content.
- **Migrations:** the 24 earlier topic-level leaf ids expand to all of their lettered
  points (`js/config/spec-id-migrations.js`), so saved coverage keeps its meaning.
- **AS H046:** 78 lettered AS points, numbered differently (AS 1.3.1 Databases = A-level
  1.3.2; AS 2.2.2(a) = A-level 1.2.3(a)). Each is matched to the A-level point with the
  highest word coverage or text similarity (recorded in `as_section_map`). Lead review
  checked all 78 and overrode two (recorded with reasons): AS 1.2.3(a) procedural
  techniques -> 1.2.4(b); AS 2.3.1(e) stacks and queues -> 1.4.2(c). AS 2.2.2(d) test
  strategies and 2.2.2(e) test data are **AS-only leaves**: the A level assesses testing
  through its coursework project, not the written papers.
- Components: H446/01 Computer systems and H446/02 Algorithms and programming, 140 marks,
  2h30 each; H046/01 and /02, 70 marks, 1h15 each (as printed in the specifications;
  each booklet's cover will be checked).
