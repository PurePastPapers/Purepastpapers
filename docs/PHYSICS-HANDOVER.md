# Physics 9PH0 / 8PH0 question bank: handover

Live working notes for the Edexcel A level Physics import (`EDX_ALEVEL_PHYS_9PH0`).
Read this first, then `docs/MATHS-HANDOVER.md` for the reference pipeline. Each
checkpoint below says exactly what is done and what remains. Nothing is called
complete while public batches are still queued.

## Checkpoint 1 — specification and source inventory (15 November 2026)

**Status: no Physics questions are imported yet.** Existing Physics papers and
questions are still the hidden demo records and generated catalogue rows.

### Specification

`data/specs/EDX_ALEVEL_PHYS_9PH0.json` is generated by `tools/physics/build_spec.py`
from Pearson's official specification PDF (Issue 3, November 2018, SHA256
`f91bef52…d90d3`; the build refuses any other revision). It replaces the earlier
unverified 13-topic/62-point catalogue.

- Leaves are the **191 official numbered statements** (`EDX_PHYS_S001`–`S191`),
  codes stored as strings, each with source PDF page and printed page.
- Tree: official Topic 1–13 (stable ids `EDX_PHYS_M1`…`M13`) → navigation group →
  statement. Groups reuse the earlier runtime skill ids (`EDX_PHYS_M2_2.1` etc.) so
  saved learned ticks keep their meaning. `js/config/spec-id-migrations.js` expands
  every earlier id into its statements when progress loads (`api.normalise`).
  `EDX_PHYS_M9_9.4` is legacy-only (its statements are in `EDX_PHYS_M9_9.3`).
  `EDX_PHYS_M10_10.1` (black body radiation) now sits under Topic 9, where Issue 3
  puts statements 153–155.
- AS 8PH0 (Issue 2, March 2016) uses identical statement numbers 1–96 (Topics 1–5).
  Those statements are `introduced_year: 12`; 97–191 are 13.
- Components: 9PH0/01 Advanced Physics I (Topics 1–3, 6–8, 90 marks, 1h45),
  9PH0/02 Advanced Physics II (Topics 1, 4, 5, 9–13, 90, 1h45), 9PH0/03 General
  and Practical Principles (all topics, 120, 2h30); 8PH0/01 Core Physics I
  (Topics 1–3, 80, 1h30), 8PH0/02 Core Physics II (Topics 1, 4, 5, 80, 1h30).
  9PH0/04 is the non-examined practical endorsement.

### Source inventory

Pearson's public past-paper search runs on a third-party search service that this
environment cannot reach, so `tools/physics/discover.py` checks Pearson file names
directly on qualifications.pearson.com (HEAD requests only, no secure paths),
seeded with URLs found by public web search. Results:

| Qualification | Public booklets | QP | MS | Examiner report | Not public |
| --- | ---: | ---: | ---: | ---: | --- |
| 9PH0 A level, 2017–2019, Oct 2020, Oct 2021, 2022–2025 | 27 | 27 | 27 | 27 | June 2026 ×3 |
| 8PH0 AS, 2016–2019, Oct 2020, Oct 2021, 2022–2025 | 20 | 20 | 20 | 20 | June 2026 ×2 |

The 2020 and 2021 series are October. Summer 2020/2021 exams were not sat. All
141 PDFs were downloaded and checksummed (`data/imports/physics/inventory/`);
June 2026 files were not public on 15 November 2026 (recorded as
`not_publicly_available` with the probe window). Official sample assessments are
in two collated PDFs (A level SAMs, 158 pages; AS SAMs, 84 pages) and still need
page-range splitting like `tools/maths/prepare_samples.py`.

Four booklets are image-only scans with no text layer: 9PH0 June 2019 Papers 1
and 2, and 8PH0 June 2019 Papers 1 and 2. They need OCR for positioning
(tesseract, installed in the session with apt), never as replacement text.

### Reproduce

```sh
python3 tools/physics/discover.py --known KNOWN_URLS.json --output ../physics-research/discovery.json
python3 tools/physics/inventory.py ../physics-research/discovery.json --out data/imports/physics/inventory
python3 tools/maths/acquire.py data/imports/physics/inventory/9ph0-inventory.json --cache ../physics-research/sources
python3 tools/maths/acquire.py data/imports/physics/inventory/8ph0-inventory.json --cache ../physics-research/sources
python3 tools/physics/inventory.py ../physics-research/discovery.json --cache ../physics-research/sources --out data/imports/physics/inventory
python3 tools/physics/build_spec.py ../physics-research/sources/SPEC.pdf   # the Issue 3 PDF
```
