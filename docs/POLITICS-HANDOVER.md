# AQA A-level Politics 7152 question bank: handover

Live working notes for the AQA A-level Politics import (`AQA_ALEVEL_POL_7152`), run
under the same brief as Physics (`docs/prompts/SUBJECT-QUESTION-BANK-AGENT.md`).
Read `docs/PHYSICS-HANDOVER.md` for the reference pipeline. Nothing is called
complete while public booklets are still queued.

## Checkpoint 1 — specification and source inventory (16 November 2026)

**Status: no Politics questions are imported yet.** The 7 existing Politics rows
are hidden demo records (now tagged to the official sections).

### Specification

`data/specs/AQA_ALEVEL_POL_7152.json` is generated by `tools/politics/build_spec.py`
from AQA's specification PDF (Version 1.2, 11 October 2022, SHA256 `4c04788b…37b68`;
the build refuses any other revision).

- Leaves are the **32 official numbered content sections** (`AQA_POL_3.1.1.1` …
  `AQA_POL_3.3.2.5`), the finest numbered level AQA prints. Each leaf stores AQA's
  key concepts and "analyse and evaluate" focus bullets verbatim, with source pages,
  so tags can cite them.
- Tree: Paper 1/2/3 → the six earlier topic ids kept as groups (`AQA_POL_UKGOV`,
  `AQA_POL_UKPOL`, `AQA_POL_USGOV`, `AQA_POL_COMP`, `AQA_POL_CORE`, `AQA_POL_OTHER`)
  → official section.
- The 31 earlier leaf ids migrate on load (`js/config/spec-id-migrations.js`, now
  written for every subject by `tools/write_spec_migrations.py`). The old
  `AQA_POL_COMP_4.5` "Pressure groups and civil rights" was two official sections
  and expands to `3.2.2.5` and `3.2.2.6`.
- Linear A level, 3 × 77 marks, 2 hours each. AQA gives no Year 12/13 split and
  there is no AS, so none is recorded or invented.

### Source inventory

`data/imports/politics/inventory/7152-inventory.json` and
`7152-samples-inventory.json` come from the JSON embedded in AQA's public
assessment-resources page (file name, publisher sha1, size). Files are fetched from
filestore.aqa.org.uk or, for June 2024/2025 and the sample papers, from AQA's
cdn.sanity.io asset URL, and every file is checked against AQA's sha1.

June 2017–2019 papers are not on AQA's public list and are not used: no secure or
teacher routes. Modified (MQP) versions are skipped because they hold the same
questions. The sample question papers on filestore are an older revision than
the listed CDN files, so the CDN revision is used.

### Rights

The owner confirmed Pearson permission on 14 November 2026. **That does not cover
AQA.** AQA papers are AQA copyright, and the copyright-removed versions show that
some third-party extracts are excluded. Nothing from AQA should go live until the
owner confirms they have permission to republish AQA material.
